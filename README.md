A short poem about agency: the power to stop and to stay.

`main.py` (Python 3.13, standard library only, no network) writes the poem to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The poem is written to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
